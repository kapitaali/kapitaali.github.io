23.1 Why Numerical Integration?¶

Two fundamental operations appear constantly in quantitative macroeconomics:

Expected utility: The Bellman equation V(a)=max⁡c{u(c)+βE[V(a′)]}V(a) = \max_c\{u(c) + \beta\mathbb{E}[V(a')]\}V(a)=maxc​{u(c)+βE[V(a′)]} requires evaluating E[V(a′)]=∫V(a′)p(a′∣a)da′\mathbb{E}[V(a')] = \int V(a')p(a'|a)da'E[V(a′)]=∫V(a′)p(a′∣a)da′ where the expectation is over the continuous distribution of next-period assets. With Gaussian income shocks: a′=(1+r)(a−c)+y′a' = (1+r)(a-c) + y'a′=(1+r)(a−c)+y′, y′∼N(μ,σ2)y' \sim \mathcal{N}(\mu, \sigma^2)y′∼N(μ,σ2), this is an integral over the normal density that has no closed form for general VVV.

The SDF moment: Asset pricing requires E[Mt+1Rt+1]=1\mathbb{E}[M_{t+1}R_{t+1}] = 1E[Mt+1​Rt+1​]=1 where Mt+1=β(ct+1/ct)−σM_{t+1} = \beta(c_{t+1}/c_t)^{-\sigma}Mt+1​=β(ct+1​/ct​)−σ and Rt+1R_{t+1}Rt+1​ has a continuous distribution. Computing this moment is a numerical integration problem.

The SCC: The social cost of carbon [P:Ch.37.2] is SCCt=−Et∫t∞e−∫tsru du∂Ys/∂Et dsSCC_t = -\mathbb{E}_t\int_t^\infty e^{-\int_t^s r_u\,du}\partial Y_s/\partial E_t\,dsSCCt​=−Et​∫t∞​e−∫ts​ru​du∂Ys​/∂Et​ds — a stochastic integral over an infinite horizon, requiring numerical quadrature.

This chapter develops three classes of methods: Newton–Cotes rules (simple but limited accuracy), Gaussian quadrature (highly accurate for smooth integrands), and Monte Carlo (flexible but slow).

23.2 Newton–Cotes Rules: Trapezoidal and Simpson’s¶

Newton–Cotes rules approximate ∫abf(x)dx\int_a^b f(x)dx∫ab​f(x)dx by replacing fff with a polynomial interpolant on a uniform grid.

Algorithm 23.1 (Composite Trapezoidal Rule).

Partition [a,b][a,b][a,b] into nnn equal subintervals of width h=(b−a)/nh = (b-a)/nh=(b−a)/n with nodes xi=a+ihx_i = a + ihxi​=a+ih:

∫abf(x) dx≈Tn(f)=h[f(x0)2+f(x1)+f(x2)+⋯+f(xn−1)+f(xn)2].\int_a^b f(x)\,dx \approx T_n(f) = h\left[\frac{f(x_0)}{2} + f(x_1) + f(x_2) + \cdots + f(x_{n-1}) + \frac{f(x_n)}{2}\right].∫ab​f(x)dx≈Tn​(f)=h[2f(x0​)​+f(x1​)+f(x2​)+⋯+f(xn−1​)+2f(xn​)​].
(1)

Theorem 23.1 (Trapezoidal Error Bound). If f∈C2[a,b]f \in C^2[a,b]f∈C2[a,b]:

∣∫abf dx−Tn(f)∣≤(b−a)h212max⁡x∈[a,b]∣f′′(x)∣=O(h2).\left|\int_a^b f\,dx - T_n(f)\right| \leq \frac{(b-a)h^2}{12}\max_{x\in[a,b]}|f''(x)| = O(h^2).∣∣​∫ab​fdx−Tn​(f)∣∣​≤12(b−a)h2​x∈[a,b]max​∣f′′(x)∣=O(h2).
(2)

Algorithm 23.2 (Composite Simpson’s Rule).

With nnn even and h=(b−a)/nh = (b-a)/nh=(b−a)/n:

∫abf dx≈Sn(f)=h3[f(x0)+4f(x1)+2f(x2)+4f(x3)+⋯+4f(xn−1)+f(xn)].\int_a^b f\,dx \approx S_n(f) = \frac{h}{3}\left[f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \cdots + 4f(x_{n-1}) + f(x_n)\right].∫ab​fdx≈Sn​(f)=3h​[f(x0​)+4f(x1​)+2f(x2​)+4f(x3​)+⋯+4f(xn−1​)+f(xn​)].
(3)

Simpson’s rule uses quadratic interpolation on each pair of subintervals.

Theorem 23.2 (Simpson’s Error Bound). If f∈C4[a,b]f \in C^4[a,b]f∈C4[a,b]:

∣∫abf dx−Sn(f)∣≤(b−a)h4180max⁡x∈[a,b]∣f(4)(x)∣=O(h4).\left|\int_a^b f\,dx - S_n(f)\right| \leq \frac{(b-a)h^4}{180}\max_{x\in[a,b]}|f^{(4)}(x)| = O(h^4).∣∣​∫ab​fdx−Sn​(f)∣∣​≤180(b−a)h4​x∈[a,b]max​∣f(4)(x)∣=O(h4).
(4)

Simpson’s converges twice as fast as trapezoidal in terms of the error exponent. For the same number of function evaluations, Simpson’s is almost always preferred.

23.3 Gaussian Quadrature¶

Newton–Cotes rules use equally spaced nodes — which is suboptimal. Gaussian quadrature chooses nodes and weights to maximize the degree of polynomial exactness for a fixed number of function evaluations.

Definition 23.1 (Gaussian Quadrature). An nnn-point Gaussian quadrature rule approximates:

∫abw(x)f(x) dx≈∑i=1nωif(xi),\int_a^b w(x)f(x)\,dx \approx \sum_{i=1}^n \omega_i f(x_i),∫ab​w(x)f(x)dx≈i=1∑n​ωi​f(xi​),
(5)

where w(x)w(x)w(x) is a weight function, the nodes {xi}\{x_i\}{xi​} are the roots of the nnn-th orthogonal polynomial with respect to www, and the weights {ωi}\{\omega_i\}{ωi​} are chosen so the rule is exact for all polynomials of degree ≤2n−1\leq 2n-1≤2n−1.

Theorem 23.3 (Exactness of Gaussian Quadrature). The nnn-point Gauss rule is exact for all polynomials of degree ≤2n−1\leq 2n-1≤2n−1. No nnn-point rule can be exact for all polynomials of degree ≤2n\leq 2n≤2n.

Proof sketch. The 2n2n2n free parameters (nodes + weights) are chosen to satisfy 2n2n2n moment conditions: exactness for 1,x,x2,…,x2n−11, x, x^2, \ldots, x^{2n-1}1,x,x2,…,x2n−1. For any rule with fixed nodes, only nnn weight conditions are available (exactness up to degree n−1n-1n−1). Gauss quadrature uses both nodes and weights as free parameters, achieving degree 2n−12n-12n−1 exactly. □\square□

23.3.1 Gauss–Hermite Quadrature for Normal Integrals¶

For integrals over the real line against the standard normal density — the most common case in macroeconomics with Gaussian shocks:

∫−∞∞f(x)ϕ(x) dx≈∑i=1nωif(xi),\int_{-\infty}^\infty f(x)\phi(x)\,dx \approx \sum_{i=1}^n \omega_i f(x_i),∫−∞∞​f(x)ϕ(x)dx≈i=1∑n​ωi​f(xi​),
(6)

where ϕ(x)=e−x2/2/2π\phi(x) = e^{-x^2/2}/\sqrt{2\pi}ϕ(x)=e−x2/2/2π​ and the nodes xix_ixi​ are roots of the nnn-th Hermite polynomial Hn(x)H_n(x)Hn​(x).

Key property: 5–10 quadrature points achieve the accuracy of 1000+ Monte Carlo draws for smooth integrands — a 100–200x speedup. This is why Gauss–Hermite quadrature is used in the inner loop of dynamic programming (Chapter 15) and in continuous-state Bellman equations.

For the general normal y∼N(μ,σ2)y \sim \mathcal{N}(\mu, \sigma^2)y∼N(μ,σ2): transform x=(y−μ)/σx = (y-\mu)/\sigmax=(y−μ)/σ, then E[f(y)]=∫f(μ+σx)ϕ(x)dx≈∑iωif(μ+σxi)\mathbb{E}[f(y)] = \int f(\mu+\sigma x)\phi(x)dx \approx \sum_i\omega_i f(\mu + \sigma x_i)E[f(y)]=∫f(μ+σx)ϕ(x)dx≈∑i​ωi​f(μ+σxi​).

Python¶

import numpy as np
from numpy.polynomial.hermite import hermgauss

def gauss_hermite_expectation(f, mu, sigma, n=7):
    """E[f(Y)] where Y ~ N(mu, sigma^2) via Gauss-Hermite quadrature."""
    # hermgauss returns nodes/weights for ∫f(x)exp(-x²)dx
    # Transform: Y = mu + sqrt(2)*sigma*x
    nodes, weights = hermgauss(n)
    y_nodes = mu + np.sqrt(2) * sigma * nodes
    return np.sum(weights * f(y_nodes)) / np.sqrt(np.pi)

# Test: E[Y^2] = mu^2 + sigma^2
f = lambda y: y**2
mu, sigma = 1.5, 0.5
result = gauss_hermite_expectation(f, mu, sigma, n=5)
exact = mu**2 + sigma**2
print(f"GH(n=5): {result:.8f}  Exact: {exact:.8f}  Error: {abs(result-exact):.2e}")

# Compare to MC for CRRA expected utility
sigma_crra = 2.0
f_crra = lambda c: c**(1-sigma_crra) / (1-sigma_crra)
mu_c, sig_c = 1.0, 0.1

print("\nExpected CRRA utility (varying n):")
for n_pts in [3, 5, 7, 10, 15]:
    result_gh = gauss_hermite_expectation(f_crra, mu_c, sig_c, n=n_pts)
    print(f"  n={n_pts:2d}: {result_gh:.10f}")

# MC benchmark
np.random.seed(42)
c_draws = np.random.normal(mu_c, sig_c, 100000)
mc_result = np.mean(f_crra(c_draws[c_draws > 0]))
print(f"  MC(100k): {mc_result:.10f}")

23.4 Monte Carlo Integration¶

Definition 23.2 (Monte Carlo Estimator). For I=∫f(x)p(x)dxI = \int f(x)p(x)dxI=∫f(x)p(x)dx where ppp is a density, the Monte Carlo estimator based on NNN draws {xi}i=1N∼p\{x_i\}_{i=1}^N \sim p{xi​}i=1N​∼p is:

I^N=1N∑i=1Nf(xi).\hat{I}_N = \frac{1}{N}\sum_{i=1}^N f(x_i).I^N​=N1​i=1∑N​f(xi​).
(7)

Theorem 23.4 (Monte Carlo Central Limit Theorem). If E[f(x)2]<∞\mathbb{E}[f(x)^2] < \inftyE[f(x)2]<∞:

N(I^N−I)→dN(0,σf2),σf2=Var[f(x)].\sqrt{N}(\hat{I}_N - I) \xrightarrow{d} \mathcal{N}(0, \sigma_f^2), \quad \sigma_f^2 = \text{Var}[f(x)].N​(I^N​−I)d​N(0,σf2​),σf2​=Var[f(x)].
(8)

The Monte Carlo standard error is σf/N\sigma_f/\sqrt{N}σf​/N​ — decreasing at rate N−1/2N^{-1/2}N−1/2 regardless of the dimension of the integration domain. This dimension-independence is Monte Carlo’s main advantage: for high-dimensional integrals (many state variables), Newton–Cotes and quadrature methods suffer from the curse of dimensionality, while Monte Carlo converges at the same rate.

23.4.1 Importance Sampling¶

When the integrand f(x)p(x)f(x)p(x)f(x)p(x) is concentrated in a small region relative to ppp, direct Monte Carlo is inefficient. Importance sampling draws from an alternative distribution q(x)q(x)q(x) that better covers the support of the integrand:

I=∫f(x)p(x)dx=∫f(x)p(x)q(x)q(x)dx≈1N∑i=1Nf(xi)p(xi)q(xi),I = \int f(x)p(x)dx = \int f(x)\frac{p(x)}{q(x)}q(x)dx \approx \frac{1}{N}\sum_{i=1}^N f(x_i)\frac{p(x_i)}{q(x_i)},I=∫f(x)p(x)dx=∫f(x)q(x)p(x)​q(x)dx≈N1​i=1∑N​f(xi​)q(xi​)p(xi​)​,
(9)

where xi∼qx_i \sim qxi​∼q. The ratio p(x)/q(x)p(x)/q(x)p(x)/q(x) is the importance weight. The optimal q∗(x)∝∣f(x)∣p(x)q^*(x) \propto |f(x)|p(x)q∗(x)∝∣f(x)∣p(x) minimizes variance, but requires knowing ∣f∣p|f|p∣f∣p up to a constant.

23.4.2 Quasi-Monte Carlo¶

Quasi-Monte Carlo (QMC) replaces pseudo-random draws with low-discrepancy sequences (Halton, Sobol) that cover the domain more uniformly. For smooth integrands in ddd dimensions, QMC achieves error O((log⁡N)d/N)O((\log N)^d/N)O((logN)d/N) — much faster than MC’s O(N−1/2)O(N^{-1/2})O(N−1/2) for moderate ddd.

23.5 Numerical Differentiation¶

Finite differences approximate derivatives when analytical formulas are unavailable or costly to derive.

Definition 23.3 (Finite Difference Approximations).

Forward difference: f′(x)≈f(x+h)−f(x)hf'(x) \approx \frac{f(x+h)-f(x)}{h}f′(x)≈hf(x+h)−f(x)​ — error O(h)O(h)O(h).

Backward difference: f′(x)≈f(x)−f(x−h)hf'(x) \approx \frac{f(x)-f(x-h)}{h}f′(x)≈hf(x)−f(x−h)​ — error O(h)O(h)O(h).

Central difference: f′(x)≈f(x+h)−f(x−h)2hf'(x) \approx \frac{f(x+h)-f(x-h)}{2h}f′(x)≈2hf(x+h)−f(x−h)​ — error O(h2)O(h^2)O(h2).

Complex step: f′(x)≈Im[f(x+ih)]/hf'(x) \approx \text{Im}[f(x+ih)]/hf′(x)≈Im[f(x+ih)]/h for complex-valued extension of fff — error O(h2)O(h^2)O(h2) but without cancellation errors (unlike real finite differences where hhh too small causes catastrophic cancellation).

Step-size selection: The optimal hhh balances truncation error (O(hp)O(h^p)O(hp) for the method) against rounding error (O(εM/h)O(\varepsilon_M/h)O(εM​/h) where εM≈10−16\varepsilon_M \approx 10^{-16}εM​≈10−16 is machine epsilon). For the central difference, the optimal step is h∗=(εM)1/3≈10−5⋅13≈10−5h^* = (\varepsilon_M)^{1/3} \approx 10^{-5\cdot\frac{1}{3}} \approx 10^{-5}h∗=(εM​)1/3≈10−5⋅31​≈10−5 (for double precision).

Automatic differentiation (AD): Modern software (PyTorch, JAX, Zygote.jl, ForwardDiff.jl) computes exact derivatives (to machine precision) of arbitrary programs via the chain rule, without finite differences. AD is increasingly preferred in DSGE estimation because it enables gradient-based optimizers for the likelihood.

23.6 Worked Example: Expected CRRA Utility Under Income Uncertainty¶

Cross-reference: Principles Ch. 11.2 (stochastic Euler equation) [P:Ch.11.2]

A household has CRRA utility u(c)=c1−σ/(1−σ)u(c) = c^{1-\sigma}/(1-\sigma)u(c)=c1−σ/(1−σ), σ=2\sigma = 2σ=2. Income next period is y′=yˉeε′y' = \bar{y}e^{\varepsilon'}y′=yˉ​eε′ where ε′∼N(0,0.04)\varepsilon' \sim \mathcal{N}(0, 0.04)ε′∼N(0,0.04) (log-normal income shocks with σε=0.2\sigma_\varepsilon = 0.2σε​=0.2). Savings sss generate next-period wealth w′=(1+r)sw' = (1+r)sw′=(1+r)s, and consumption c′=w′+y′c' = w' + y'c′=w′+y′. We wish to compute:

E[u(c′)]=E ⁣[(w′+yˉeε′)1−σ1−σ].\mathbb{E}[u(c')] = \mathbb{E}\!\left[\frac{(w' + \bar{y}e^{\varepsilon'})^{1-\sigma}}{1-\sigma}\right].E[u(c′)]=E[1−σ(w′+yˉ​eε′)1−σ​].
(10)

Method 1 — Gauss–Hermite (7 points): Transform ε′=2σεz\varepsilon' = \sqrt{2}\sigma_\varepsilon zε′=2​σε​z; compute at 7 nodes.

Method 2 — Monte Carlo (100,000 draws): Direct simulation.

Method 3 — Trapezoidal rule: Integrate over a finite range [−3σε,3σε][-3\sigma_\varepsilon, 3\sigma_\varepsilon][−3σε​,3σε​].

import numpy as np
from numpy.polynomial.hermite import hermgauss
from scipy.stats import norm

sigma_crra, r, w_prime_val = 2.0, 0.04, 1.0
y_bar, sigma_eps = 1.0, 0.20

def u(c): return c**(1-sigma_crra)/(1-sigma_crra) if c > 0 else -1e20
def u_vec(c): return np.where(c > 1e-10, c**(1-sigma_crra)/(1-sigma_crra), -1e20)

def E_u_gauss_hermite(w_prime, n=7):
    nodes, weights = hermgauss(n)
    # eps' = sqrt(2)*sigma_eps*z (change of variables for hermgauss)
    eps = np.sqrt(2)*sigma_eps*nodes
    c_prime = w_prime + y_bar*np.exp(eps)
    return np.sum(weights * u_vec(c_prime)) / np.sqrt(np.pi)

def E_u_montecarlo(w_prime, N=100000):
    eps = np.random.normal(0, sigma_eps, N)
    c_prime = w_prime + y_bar*np.exp(eps)
    return np.mean(u_vec(c_prime))

def E_u_trapezoidal(w_prime, n=1000):
    eps_range = 3*sigma_eps
    eps_grid = np.linspace(-eps_range, eps_range, n)
    c_prime = w_prime + y_bar*np.exp(eps_grid)
    integrand = u_vec(c_prime) * norm.pdf(eps_grid, 0, sigma_eps)
    h = 2*eps_range/(n-1)
    return h*(0.5*integrand[0] + np.sum(integrand[1:-1]) + 0.5*integrand[-1])

np.random.seed(42)
print("Expected utility comparison (w'=1.0, σ=2, σ_eps=0.2):")
print(f"  Gauss-Hermite (n=7):     {E_u_gauss_hermite(w_prime_val, 7):.8f}")
print(f"  Gauss-Hermite (n=15):    {E_u_gauss_hermite(w_prime_val, 15):.8f}")
print(f"  Monte Carlo (N=100k):    {E_u_montecarlo(w_prime_val):.8f}")
print(f"  Trapezoidal (n=1000):    {E_u_trapezoidal(w_prime_val):.8f}")

# Efficiency comparison: time for 1% accuracy
import time
for method, func in [("GH-7", lambda: E_u_gauss_hermite(1.0, 7)),
                     ("GH-15", lambda: E_u_gauss_hermite(1.0, 15)),
                     ("MC-1k", lambda: E_u_montecarlo(1.0, 1000)),
                     ("Trap-100", lambda: E_u_trapezoidal(1.0, 100))]:
    t0 = time.perf_counter()
    [func() for _ in range(100)]
    elapsed = (time.perf_counter()-t0)/100
    print(f"  {method}: {elapsed*1e6:.1f} μs per evaluation")

Exercise 23.3 (Julia — Automatic Differentiation)¶

using ForwardDiff

# Jacobian of NK steady-state conditions via AD
alpha, delta, beta = 0.36, 0.025, 0.99; n = 1/3; pi_bar = 1.005

function nk_ss(x)
    C,K,Y,w,r,pi_,mc = x
    [Y - K^alpha*n^(1-alpha),
     1 - beta*(1+r),
     r - (alpha*Y/K - delta),
     w - (1-alpha)*Y/n,
     mc - w/((1-alpha)*Y/n),
     pi_ - pi_bar,
     C - (Y - delta*K)]
end

r_star = 1/beta - 1
K_star = (alpha/(r_star+delta))^(1/(1-alpha))
x_star = [0.65, K_star, 1.0, 1.5, r_star, pi_bar, 0.95]

# AD Jacobian (exact, no finite differences!)
J_ad = ForwardDiff.jacobian(nk_ss, x_star)
println("Condition number of Jacobian: ", round(cond(J_ad), digits=2))
println("Max eigenvalue:               ", round(maximum(abs.(eigvals(J_ad))), digits=4))

# Compare to finite-difference Jacobian
h = 1e-7
J_fd = zeros(7, 7)
F0 = nk_ss(x_star)
for j in 1:7
    xp = copy(x_star); xp[j] += h
    J_fd[:,j] = (nk_ss(xp) - F0) / h
end
println("Max error (AD vs FD): ", maximum(abs.(J_ad - J_fd)))

23.8 Chapter Summary¶
