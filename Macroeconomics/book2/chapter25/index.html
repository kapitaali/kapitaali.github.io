From Linear Systems to Sparse Matrices

“Every time you call a linear solver, LU decomposition is happening — whether you know it or not.”

Cross-reference: Principles Ch. 4 (Leontief input-output, matrix inversion); Ch. 9 (IS–LM as linear system); Ch. 27 (DSGE equilibrium conditions as large sparse system) [P:Ch.4, P:Ch.9, P:Ch.27]

25.1 The Ubiquity of Linear Systems in Macroeconomics¶

Linear systems Ax=bA\mathbf{x} = \mathbf{b}Ax=b appear at every stage of the macroeconomic modeling workflow:

  • IS–LM: The 2×22\times22×2 system from Chapter 6, solved by b ⌹ A in APL.

  • Leontief inverse: (I−A)−1d(I-A)^{-1}\mathbf{d}(I−A)−1d, a dense n×nn\times nn×n system for nnn sectors.

  • Kalman filter: Prediction step Ppred=FPF′+QP_{\text{pred}} = FPF' + QPpred​=FPF′+Q requires matrix multiplication; the innovation variance Ft=HPH′+RF_t = HPH' + RFt​=HPH′+R and gain K=PH′Ft−1K = PH'F_t^{-1}K=PH′Ft−1​ require matrix inversion.

  • DSGE log-linearization: The linearized first-order conditions form a large sparse system; the Sylvester equation for the MSV solution is a vectorized linear system.

  • Value function iteration: The Howard policy improvement step solves (I−βP)V=u(I-\beta P)V = u(I−βP)V=u, where PPP is the N×NN\times NN×N Markov transition matrix (sparse).

Understanding how linear systems are solved — not just that they are — enables better debugging, performance tuning, and recognition of when standard methods will fail.

25.2 LU Decomposition: Direct Method for Dense Systems¶

Definition 25.1 (LU Decomposition). The LU decomposition of an invertible matrix A∈Rn×nA \in \mathbb{R}^{n\times n}A∈Rn×n is the factorization PA=LUPA = LUPA=LU, where:

  • PPP is a permutation matrix (row reordering for numerical stability).

  • LLL is unit lower triangular: lii=1l_{ii} = 1lii​=1, lij=0l_{ij} = 0lij​=0 for j>ij > ij>i.

  • UUU is upper triangular: uij=0u_{ij} = 0uij​=0 for j<ij < ij<i.

Algorithm 25.1 (LU Decomposition with Partial Pivoting).

For k=1,…,n−1k = 1, \ldots, n-1k=1,…,n−1:

  1. Find the pivot: p=arg⁡max⁡i≥k∣aik∣p = \arg\max_{i\geq k}|a_{ik}|p=argmaxi≥k​∣aik​∣ (largest absolute value in column kkk at or below the diagonal).

  2. Swap rows kkk and ppp in AAA.

  3. For i=k+1,…,ni = k+1, \ldots, ni=k+1,…,n: lik=aik/akkl_{ik} = a_{ik}/a_{kk}lik​=aik​/akk​ (elimination multipliers).

  4. For i=k+1,…,ni = k+1, \ldots, ni=k+1,…,n: ai,k:n←ai,k:n−lik⋅ak,k:na_{i,k:n} \leftarrow a_{i,k:n} - l_{ik}\cdot a_{k,k:n}ai,k:n​←ai,k:n​−lik​⋅ak,k:n​ (row elimination).

Theorem 25.1 (LU Complexity). The LU decomposition of an n×nn\times nn×n matrix requires O(n3/3)O(n^3/3)O(n3/3) flops for elimination plus O(n2)O(n^2)O(n2) for forward/back substitution to solve Ax=bA\mathbf{x} = \mathbf{b}Ax=b.

Proof. In the kkk-th elimination step, the inner loop performs (n−k)2(n-k)^2(n−k)2 operations. Total: ∑k=1n−1(n−k)2≈n3/3\sum_{k=1}^{n-1}(n-k)^2 \approx n^3/3∑k=1n−1​(n−k)2≈n3/3. □\square□

Solving Ax=bA\mathbf{x} = \mathbf{b}Ax=b via LU:

  1. Factor: PA=LUPA = LUPA=LU (cost O(n3/3)O(n^3/3)O(n3/3)).

  2. Forward substitution: solve Ly=PbL\mathbf{y} = P\mathbf{b}Ly=Pb for y\mathbf{y}y (cost O(n2)O(n^2)O(n2)).

  3. Back substitution: solve Ux=yU\mathbf{x} = \mathbf{y}Ux=y for x\mathbf{x}x (cost O(n2)O(n^2)O(n2)).

For multiple right-hand sides b1,…,bk\mathbf{b}_1, \ldots, \mathbf{b}_kb1​,…,bk​ with the same AAA: factor once (O(n3)O(n^3)O(n3)), then solve each in O(n2)O(n^2)O(n2). This is the key efficiency insight for the Kalman filter: the innovation covariance FtF_tFt​ changes at each time step, so each inversion is a separate O(p3)O(p^3)O(p3) cost; but if FtF_tFt​ is constant (stationary model), it is factored once.

Condition number and numerical stability:

Definition 25.2 (Condition Number). The condition number of a matrix AAA is:

κ(A)=∥A∥⋅∥A−1∥.\kappa(A) = \|A\|\cdot\|A^{-1}\|.κ(A)=∥A∥⋅∥A−1∥.
(1)

The relative error in the computed solution x^\hat{\mathbf{x}}x^ satisfies:

∥x^−x∗∥∥x∗∥≤κ(A)⋅εM+O(εM2),\frac{\|\hat{\mathbf{x}} - \mathbf{x}^*\|}{\|\mathbf{x}^*\|} \leq \kappa(A)\cdot\varepsilon_M + O(\varepsilon_M^2),∥x∗∥∥x^−x∗∥​≤κ(A)⋅εM​+O(εM2​),
(2)

where εM≈10−16\varepsilon_M \approx 10^{-16}εM​≈10−16 is machine epsilon. A well-conditioned matrix (κ(A)≈1\kappa(A) \approx 1κ(A)≈1) introduces negligible numerical error; a poorly conditioned matrix (κ(A)∼1012\kappa(A) \sim 10^{12}κ(A)∼1012) can lose 12 digits of accuracy in the solution.

Partial pivoting (choosing the largest pivot) reduces condition number amplification: it ensures that the elements of LLL satisfy ∣lij∣≤1|l_{ij}| \leq 1∣lij​∣≤1, bounding the growth of rounding errors.

In APL, ⌹A calls LAPACK’s DGETRF/DGETRS (LU with partial pivoting) internally. The solution b ⌹ A is equivalent to LU-factoring AAA and solving — but APL’s ⌹ handles the complete pipeline automatically.

25.3 Iterative Methods for Large Systems¶

When nnn is very large (hundreds of thousands of variables in heterogeneous-agent models), direct LU is impractical (O(n3)O(n^3)O(n3) is too slow). Iterative methods compute approximate solutions by successive refinement.

25.3.1 Gauss–Seidel¶

Algorithm 25.2 (Gauss–Seidel).

For a system Ax=bA\mathbf{x} = \mathbf{b}Ax=b, decompose A=D+L+UA = D + L + UA=D+L+U (diagonal, strict lower, strict upper triangular).

Initialize x(0)\mathbf{x}^{(0)}x(0). For k=0,1,2,…k = 0, 1, 2, \ldotsk=0,1,2,…:

xi(k+1)=1aii(bi−∑j<iaijxj(k+1)−∑j>iaijxj(k)),i=1,…,n.x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j<i}a_{ij}x_j^{(k+1)} - \sum_{j>i}a_{ij}x_j^{(k)}\right), \quad i = 1, \ldots, n.xi(k+1)​=aii​1​(bi​−j<i∑​aij​xj(k+1)​−j>i∑​aij​xj(k)​),i=1,…,n.
(3)

Each element is updated using the most recent values of all other elements.

Convergence: Gauss–Seidel converges (to the true solution) iff the spectral radius ρ(−(D+L)−1U)<1\rho(-(D+L)^{-1}U) < 1ρ(−(D+L)−1U)<1. A sufficient condition is that AAA is strictly diagonally dominant: ∣aii∣>∑j≠i∣aij∣|a_{ii}| > \sum_{j\neq i}|a_{ij}|∣aii​∣>∑j=i​∣aij​∣ for all iii.

25.3.2 Conjugate Gradient for SPD Systems¶

For symmetric positive definite (SPD) systems — which arise in the normal equations of least squares, the Howard policy improvement step with symmetric PPP, and certain DSGE Hessians — the Conjugate Gradient (CG) method achieves faster convergence.

Algorithm 25.3 (Conjugate Gradient).

Initialize x(0)=0\mathbf{x}^{(0)} = \mathbf{0}x(0)=0, r(0)=b\mathbf{r}^{(0)} = \mathbf{b}r(0)=b, p(0)=r(0)\mathbf{p}^{(0)} = \mathbf{r}^{(0)}p(0)=r(0).

For k=0,1,2,…k = 0, 1, 2, \ldotsk=0,1,2,…:

  1. αk=(r(k))′(r(k))/[(p(k))′Ap(k)]\alpha_k = (\mathbf{r}^{(k)})'(\mathbf{r}^{(k)}) / [(\mathbf{p}^{(k)})'A\mathbf{p}^{(k)}]αk​=(r(k))′(r(k))/[(p(k))′Ap(k)]

  2. x(k+1)=x(k)+αkp(k)\mathbf{x}^{(k+1)} = \mathbf{x}^{(k)} + \alpha_k\mathbf{p}^{(k)}x(k+1)=x(k)+αk​p(k)

  3. r(k+1)=r(k)−αkAp(k)\mathbf{r}^{(k+1)} = \mathbf{r}^{(k)} - \alpha_kA\mathbf{p}^{(k)}r(k+1)=r(k)−αk​Ap(k)

  4. βk=(r(k+1))′(r(k+1))/[(r(k))′(r(k))]\beta_k = (\mathbf{r}^{(k+1)})'(\mathbf{r}^{(k+1)}) / [(\mathbf{r}^{(k)})'(\mathbf{r}^{(k)})]βk​=(r(k+1))′(r(k+1))/[(r(k))′(r(k))]

  5. p(k+1)=r(k+1)+βkp(k)\mathbf{p}^{(k+1)} = \mathbf{r}^{(k+1)} + \beta_k\mathbf{p}^{(k)}p(k+1)=r(k+1)+βk​p(k)

Theorem 25.2 (CG Convergence). CG converges to the exact solution in at most nnn steps. The error after kkk steps satisfies:

∥x∗−x(k)∥A≤2(κ−1κ+1)k∥x∗−x(0)∥A,\|\mathbf{x}^* - \mathbf{x}^{(k)}\|_A \leq 2\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k\|\mathbf{x}^*-\mathbf{x}^{(0)}\|_A,∥x∗−x(k)∥A​≤2(κ​+1κ​−1​)k∥x∗−x(0)∥A​,
(4)

where ∥v∥A=v′Av\|\mathbf{v}\|_A = \sqrt{\mathbf{v}'A\mathbf{v}}∥v∥A​=v′Av​ and κ=κ(A)\kappa = \kappa(A)κ=κ(A).

25.4 Sparse Matrix Methods¶

Many macroeconomic linear systems are sparse: most elements are zero, and the non-zero structure has economic meaning.

Leontief model: The n×nn\times nn×n technical coefficient matrix AAA for an nnn-sector economy has at most n2n^2n2 entries, but in practice each sector uses inputs from only a few others — AAA is sparse. For n=500n = 500n=500 sectors, storing AAA densely requires 5002=250,000500^2 = 250{,}0005002=250,000 entries; storing sparsely requires only the non-zero entries (perhaps 5,0005{,}0005,000–10,00010{,}00010,000).

DSGE Jacobian: The gradient and Hessian of the DSGE log-likelihood have a block structure corresponding to the model’s timing restrictions — many parameters affect only specific equations and specific periods.

Sparse storage formats:

  • CSR (Compressed Sparse Row): Store all non-zero values, their column indices, and row start pointers. Matrix-vector products AvA\mathbf{v}Av cost O(nnz)O(\text{nnz})O(nnz) where nnz\text{nnz}nnz is the number of non-zeros.

  • CSC (Compressed Sparse Column): Same structure transposed. Preferred for column-oriented operations.

  • COO (Coordinate format): List of (i,j,v)(i, j, v)(i,j,v) triples. Convenient for construction, converted to CSR/CSC for computation.

25.5 Overdetermined Systems: Least Squares¶

Many estimation problems yield overdetermined systems Ax≈bA\mathbf{x} \approx \mathbf{b}Ax≈b with m>nm > nm>n equations and nnn unknowns. The OLS solution minimizes ∥b−Ax∥22\|\mathbf{b} - A\mathbf{x}\|_2^2∥b−Ax∥22​.

25.5.1 Normal Equations¶

The OLS solution satisfies the normal equations:

A′Ax∗=A′b  ⟹  x∗=(A′A)−1A′b.A'A\mathbf{x}^* = A'\mathbf{b} \implies \mathbf{x}^* = (A'A)^{-1}A'\mathbf{b}.A′Ax∗=A′b⟹x∗=(A′A)−1A′b.
(5)

In APL: x_ols ← (⌹ X) +.× y — already derived in Chapter 19 for VAR estimation. This uses the pseudo-inverse A+=(A′A)−1A′A^+ = (A'A)^{-1}A'A+=(A′A)−1A′.

25.5.2 QR Decomposition¶

The QR decomposition is numerically superior to forming A′AA'AA′A (which squares the condition number):

Definition 25.3 (QR Decomposition). For A∈Rm×nA \in \mathbb{R}^{m\times n}A∈Rm×n (m≥nm \geq nm≥n, full column rank): A=QRA = QRA=QR where Q∈Rm×nQ \in \mathbb{R}^{m\times n}Q∈Rm×n is orthonormal (Q′Q=InQ'Q = I_nQ′Q=In​) and R∈Rn×nR \in \mathbb{R}^{n\times n}R∈Rn×n is upper triangular.

The OLS solution via QR: Ax∗=b⇒QRx∗=b⇒Rx∗=Q′bA\mathbf{x}^* = \mathbf{b} \Rightarrow QR\mathbf{x}^* = \mathbf{b} \Rightarrow R\mathbf{x}^* = Q'\mathbf{b}Ax∗=b⇒QRx∗=b⇒Rx∗=Q′b, solved by back substitution.

Advantage of QR: κ(R)=κ(A)\kappa(R) = \kappa(A)κ(R)=κ(A), whereas κ(A′A)=κ(A)2\kappa(A'A) = \kappa(A)^2κ(A′A)=κ(A)2. For a moderately ill-conditioned system with κ(A)=108\kappa(A) = 10^8κ(A)=108, normal equations have κ(A′A)=1016\kappa(A'A) = 10^{16}κ(A′A)=1016 — at the limit of double precision. QR avoids this squaring.

Cross-reference: Principles Ch. 4.5 (input-output analysis) [P:Ch.4.5]

# Chapter 25: Stress Testing the Leontief System
library(Matrix)

# 1. Scale up to 2000 sectors
n <- 2000
set.seed(42)

# Create a technical coefficient matrix (Dense)
A <- matrix(runif(n*n, 0, 0.001), n, n) # Smaller values for larger n
A <- A / outer(rep(1, n), colSums(A) + 0.5)
d <- rep(10, n)
I_n <- Diagonal(n) # Use Diagonal() for efficiency

# --- Dense Solver ---
cat("Running Dense Solver (O(n^3))...\n")
t_dense <- system.time(x_dense <- solve(as.matrix(I_n - A), d))[3]
cat(sprintf("Dense:  %.2f seconds\n", t_dense))

# --- Sparse Solver ---
cat("Running Sparse Solver (O(nnz^1.5))...\n")

A_sp[A_sp < 0.0002] <- 0  # Lower threshold to keep ~20% of entries

# --- Precision Check ---
res_dense <- max(abs((I_n - A) %*% x_dense - d))
res_sparse <- max(abs((I_n - A_sp) %*% x_sparse - d))

Python¶

import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as sla
import time

np.random.seed(42)
n = 100

# Dense random technical coefficient matrix (sparse in practice)
A_dense = np.random.uniform(0, 0.1, (n,n))  # small coefficients
# Ensure productive: column sums < 1
A_dense /= (A_dense.sum(axis=0) + 0.5)
d = np.ones(n) * 10  # final demand

# Dense solution
t0 = time.perf_counter()
x_dense = np.linalg.solve(np.eye(n) - A_dense, d)
t_dense = time.perf_counter() - t0
print(f"Dense LU:    {t_dense*1000:.2f} ms, max residual: {np.max(np.abs((np.eye(n)-A_dense)@x_dense - d)):.2e}")

# Sparse solution (keep only entries > 0.05)
A_sparse = A_dense.copy(); A_sparse[A_sparse < 0.05] = 0
A_sp = sp.csr_matrix(np.eye(n) - A_sparse)
t0 = time.perf_counter()
x_sparse = sla.spsolve(A_sp, d)
t_sparse = time.perf_counter() - t0
nnz = A_sp.nnz
print(f"Sparse LU:   {t_sparse*1000:.2f} ms, nnz={nnz}/{n**2} ({100*nnz/n**2:.1f}%), max residual: {np.max(np.abs(A_sp@x_sparse - d)):.2e}")

# Output multipliers (column sums of Leontief inverse)
L = np.linalg.inv(np.eye(n) - A_dense)
multipliers = L.sum(axis=0)
print(f"\nOutput multipliers: mean={multipliers.mean():.3f}, max={multipliers.max():.3f}, min={multipliers.min():.3f}")

Exercise 25.3 (Julia — QR vs. Normal Equations)¶

using LinearAlgebra

# Demonstrate numerical superiority of QR over normal equations
function test_ols(m, n, cond_number)
    # Generate a matrix with specified condition number
    U,_,V = svd(randn(m,n))
    s = range(1, cond_number, length=n)
    A = U[:,1:n] * diagm(s) * V'
    x_true = randn(n)
    b = A*x_true + 0.01*randn(m)
    
    # Normal equations
    x_ne = (A'*A) \ (A'*b)
    err_ne = norm(x_ne - x_true)
    
    # QR
    Q,R = qr(A)
    x_qr = R \ (Matrix(Q)'*b)
    err_qr = norm(x_qr - x_true)
    
    return err_ne, err_qr, cond(A'*A)
end

println("Condition number comparison:")
